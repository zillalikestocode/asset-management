# AssetFlow — Product Demo Video Script

**Target length:** 4–6 minutes  
**Format:** Screen recording + voiceover (face-cam in corner optional)  
**Audience:** Operations managers and maintenance leads at manufacturing SMEs  
**Goal:** Show the full end-to-end workflow; close with a "book a call" CTA

---

## Before You Record

- Use a demo org named something realistic, e.g. **"Meridian Manufacturing"**
- Pre-populate the demo with 8–12 assets across 2–3 locations (e.g. *Assembly Line A*, *Packaging*, *Utilities Room*)
- Have 2–3 open work orders and 1 overdue PM ready to show
- Use a second browser profile or phone for the technician view
- Record at 1080p minimum; 4K if your screen cap tool supports it
- Move the cursor slowly and deliberately — faster than natural speech feels rushed on screen
- Pause 1–2 seconds on each new screen before speaking so viewers can orient

## Production Notes

### Pacing
- Speak at a natural conversational pace — not rushed, not slow
- Pause 1–2 seconds after navigating to a new screen before speaking
- Keep mouse movement deliberate; avoid erratic cursor movement

### Tone
- Confident, direct, peer-to-peer — you're talking to someone who knows their floor
- Avoid marketing language ("revolutionary", "game-changing") — manufacturing managers tune it out
- Use real-sounding names: Marcus, Meridian Manufacturing, CNC Machine 04, Press Line 2

### Editing
- Cut dead air aggressively — remove pauses longer than 1.5s
- Use subtle zoom-in transitions when clicking into a detail view
- Add callout boxes or cursor highlights for key UI elements (QR code, status badges, work order form)
- Consider a short lower-third at the start: **"AssetFlow — Asset management for manufacturing teams"**
- Fade out with the AssetFlow logo + website URL + "Book a call" CTA on screen

### Screen Setup
- Use a clean browser — hide bookmarks bar, close irrelevant tabs
- Set system UI to Do Not Disturb before recording
- Use a dark-mode OS theme if possible to match the AssetFlow dark UI aesthetic

### Optional Additions
- Add a short before/after moment at the top (5s of the spreadsheet, then cut to the dashboard)
- Record a 90-second short cut (Scenes 2, 3, 4, 6 only) for social media / ads
