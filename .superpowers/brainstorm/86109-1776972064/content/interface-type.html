Question 4: What's the primary interface for the MVP?

Manufacturing workers use tools in the field. Where does the software live?

A

Web App Only

Desktop browser-based dashboard. Managers and admins track assets from the office. Fast to build, no app store needed.

Pros

  • Fastest to build
  • No installs
  • Easy updates

Cons

  • Not ideal for field workers
  • No offline mode
  • Barcode scan needs add-on
B

Mobile App First

Native or PWA mobile app for technicians scanning barcodes and logging work in the field. Managers use the same app.

Pros

  • Barcode & GPS built-in
  • Field-worker friendly
  • Offline capable

Cons

  • Harder to build
  • App store approval
  • Two platforms (iOS + Android)
C

Web App + Mobile PWA

Responsive web app that works on desktop and mobile browser. Field workers use mobile browser to scan barcodes (camera). Managers get full dashboard on desktop.

Pros

  • One codebase
  • Camera-based scanning
  • No app store needed

Cons

  • Limited offline support
  • Camera scan less reliable than dedicated scanner
